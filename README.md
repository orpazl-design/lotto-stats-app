# סטטיסטיקת הגרלות הלוטו

אפליקציה קטנה שמורידה את היסטוריית הגרלות הלוטו הרשמית ממפעל הפיס, ומציגה
דוח סטטיסטיקות: אילו מספרים הופיעו הכי הרבה, אילו הכי פחות, ואילו לא הופיעו
כבר הכי הרבה זמן.

## חשוב לדעת לפני שמשתמשים בזה

הגרלת הלוטו היא אירוע אקראי ובלתי תלוי בהגרלות קודמות. **אין שום דרך אמיתית
לחזות מה יזכה בהגרלה הבאה**, וההיסטוריה של מספר מסוים לא משנה את הסיכוי שלו
בהגרלה הבאה. האפליקציה מציגה נתונים היסטוריים אמיתיים ומייצרת גם "הצעת
מספרים" משוקללת לפי תדירות — אבל זה בשביל הכיף בלבד, לא ניבוי.

## איך מריצים

הכי פשוט: לחיצה כפולה על `run.bat`. זה יוריד נתונים עדכניים ויפתח את הדוח
בדפדפן.

להרצה ידנית משורת הפקודה:

```
py fetch_data.py     # מוריד CSV עדכני ממפעל הפיס לתוך data/lotto_raw.csv
py build_report.py   # בונה את report.html מהנתונים שהורדו
```

## מקור הנתונים

`https://www.pais.co.il/lotto/archive.aspx` — הקובץ מוריד ישירות מהקישור
הרשמי להורדת תוצאות בפורמט CSV. הנתונים מסוננים לתקופה שבה כללי המשחק זהים
לכללים הנוכחיים (6 מספרים מתוך 1–37 + מספר חזק מתוך 1–7), כלומר מ-05/03/2011
ואילך; הגרלות ישנות יותר פעלו לפי כללים שונים ולכן לא נכללות.

## הערה טכנית: Avast SSL

אם המחשב מריץ Avast עם סריקת SSL, `fetch_data.py` מדלג על אימות תעודת ה-SSL
עבור ההורדה הזו בלבד (`verify=False`), כי Avast מחליף את התעודה המקורית
בתעודה חתומה משלו שלא נמצאת ברשימת האמון של Python. Windows כבר סומך על
Avast, כך שזה לא פותח סיכון אמיתי נוסף במחשב הזה.

## קבצים

- `fetch_data.py` — מוריד ומנקה את נתוני ההגרלות
- `build_report.py` — מחשב סטטיסטיקות ובונה את `report.html`
- `run.bat` — מריץ את שני הסקריפטים ופותח את הדוח
- `data/lotto_raw.csv` — הנתונים הגולמיים שהורדו (נוצר אוטומטית)
- `report.html` — הדוח הסופי (נוצר אוטומטית, אפשר לפתוח בכל דפדפן)
